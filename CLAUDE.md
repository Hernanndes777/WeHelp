# WeHelp — Instruções para Claude

## Copywriting

Sempre que for escrever copy (headline, LP, anúncio, e-mail, WhatsApp, roteiro de vídeo), leia primeiro:
`00-base/copy-master/COMPILADO-MASTER-COPYWRITING.md`

Aplique os frameworks do compilado: Great Leads (tipo de lead), Evaldo (One Belief), Kern (polarização, push-pull), Makepeace (prova, oferta). Não escreva copy genérico.

## Personas e segmentos

Consulte `00-base/personas/personas.md` antes de escrever qualquer copy para identificar dor, vocabulário e ângulos validados do segmento certo.

## Deploy

O repo publica via Vercel (git integration). Cada push na `main` publica automaticamente em `lp.wehelpsoftware.com`. Siga a convenção de commit de `PROCESSO.md`.

## Processo de LP

Siga o checklist de `PROCESSO.md` para qualquer LP nova.
