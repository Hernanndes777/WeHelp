# Índice de Produtos — WeHelp

A WeHelp é uma **plataforma de Experiência do Cliente (CX)**. Hoje tem 3 módulos:

| Módulo | O que faz | Status | Dossiê |
|---|---|---|---|
| **Pesquisa de Satisfação** | Software de NPS® — envia pesquisas (email/SMS/widget/QR), coleta e organiza respostas, dashboards + eNPS pra colaboradores | Produto base, bem documentado | [`pesquisa-satisfacao/pesquisa-satisfacao.md`](pesquisa-satisfacao/pesquisa-satisfacao.md) |
| **Módulo de Retenção de Churn** | Identifica alunos/clientes em risco de cancelamento antes que aconteça, com análise preditiva e alertas | 🆕 Lançado recentemente, bem documentado | [`modulo-retencao-churn/modulo-retencao-churn.md`](modulo-retencao-churn/modulo-retencao-churn.md) |
| **Módulo de Ticket** | Provável gestão de chamados a partir de feedback negativo — **não confirmado ainda** | Existe, detalhe pendente | [`modulo-ticket/modulo-ticket.md`](modulo-ticket/modulo-ticket.md) |

Metodologia de NPS (Promotores/Passivos/Detratores, cálculo, faixas) documentada em [`../metodologia-nps.md`](../metodologia-nps.md) — reaproveitável em qualquer LP educativa.

## Como os módulos se conectam na narrativa de copy

A lógica dos 3 módulos segue o ciclo de CX: **ouvir → prever → agir**.

1. **Pesquisa de Satisfação** = ouvir o cliente (a voz do cliente vira dado).
2. **Módulo de Retenção de Churn** = prever quem vai sair antes que saia, usando os dados coletados + comportamento.
3. **Módulo de Ticket** = agir/resolver o problema que gerou insatisfação.

Isso importa pra copy: uma LP de "Retenção" pode mencionar que os dados vêm da Pesquisa de Satisfação; uma LP de upsell pode oferecer o próximo módulo do ciclo pra quem já usa um.
